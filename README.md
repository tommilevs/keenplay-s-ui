# Unixplay S-UI adapter

This beta adapter packages the existing S-UI Keenetic installer for Unixplay. English is the primary language; Russian follows below.

The upstream installer is pinned to an immutable commit. The adapter exposes install, update, remove, status, and ttyd terminal metadata through `unixplay.yaml`.

## Русский

Beta-адаптер упаковывает существующий установщик S-UI для Unixplay. Установщик upstream закреплён на неизменяемом commit. Через `unixplay.yaml` доступны установка, обновление, удаление, статус и терминальный режим ttyd.

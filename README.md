# KeenPlay S-UI adapter

This beta adapter packages the existing S-UI Keenetic installer for Playkeen. English is the primary language; Russian follows below.

The upstream installer is pinned to an immutable commit. The adapter exposes install, update, remove, status, and ttyd terminal metadata through `playkeen.yaml`.

## Русский

Beta-адаптер упаковывает существующий установщик S-UI для Playkeen. Установщик upstream закреплён на неизменяемом commit. Через `playkeen.yaml` доступны установка, обновление, удаление, статус и терминальный режим ttyd.
